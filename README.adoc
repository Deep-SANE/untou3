= UNtoU3 C++ library

:stem: latexmath

Contents of the UNtoU3 package:

* `include/UNtoU3.h` - main header file to be included into {cpp}20 enabled source code.

* `src/test_10401.cpp` - test source file for U(6) irrep stem:[[4,2,2,2,2,0\]].

* `src/test_input.cpp` - benchmark source file that takes n, r4, r3, r2, r1, and r0 as user inputs and optionaly (with BOOST) verify level dimensionalities or generated U3 irreps.

For building test programs, run `make`. Configuration of the build process (compiler, flags, optional BOOST path) is specified by environment variables.
